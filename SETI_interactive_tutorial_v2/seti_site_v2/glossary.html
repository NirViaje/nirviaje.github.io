术语速查（教学时最常被问的）

主行动 Main Action
你的回合“只能做一件大事”。Launch/Scan/Land/Analyze/Research/Play/Pass 等。
免费行动 Free Action
可穿插在主行动前后，但只能在你自己的回合。例：能量换移动、资源交换、买卡、放数据。
声望 Publicity
代表公众关注与科研影响力，核心用途：支付 6 点研究科技。
数据 Data
你收集到的观测/采样。数据池上限 6；放进电脑触发奖励；电脑上排满才可 Analyze。
星区 Sector
天空划分的区域。通过 Scan 或卡牌放“信号标记”。填满后结算赢家并重置。
发现 Discovery
某外星种族的 3 个发现格被填满就翻开板块，按该种族规则继续游戏。
太阳系旋转 Rotate
研究科技时必触发；每轮首位 Pass 也会触发。旋转可能“推动/挤压”探测器。

一分钟“话术模板”（你可以直接复制给玩家）

你只要记住三条链：
1）扫描：花信用+能量 → 放信号 → 拿数据 → 竞争星区 → 得分/线索
2）探测：发射→移动→环绕/登陆 → 拿数据/分数/线索
3）分析：数据进电脑 → 上排满 → 分析 → 线索 → 触发外星发现

科技与卡牌是放大器：让你同样的主行动“做得更多、更便宜、更稳”。

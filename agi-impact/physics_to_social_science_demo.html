一组最适合从 K12 物理导入的社会模型

每张卡片都遵循同一个逻辑：物理原型 → 公式 → 社会翻译 → 为什么这件事震撼。先把这些看成“母模型”，再去看下面的可视化模拟，会更容易理解。

传播 / 增长

指数增长

dI/dt = rI

早期传播中，已经传播的人越多，新增加的人也越多。热点、模因、平台增长在早期常近似符合这一形式。

  • 物理对应：放射性衰变、充放电近似
  • 社会对应：消息爆发、用户增长、观念扩散
  • 关键直觉：复制率决定爆发速度
传播 / 疫病 / 舆情

SIR 模型

dS/dt = -βSI   ;   dI/dt = βSI - γI   ;   dR/dt = γI

一条消息、一个谣言、一个挑战赛，很多时候不是“大家都喜欢”，而是“接触传播 + 退出传播”的结果。

  • 物理对应：粒子碰撞 / 接触改变状态
  • 社会对应：谣言、爆款、流行文化、讨论热度
  • 关键直觉：传播率 β 与退出率 γ 的竞赛
极化 / 从众

Ising 意见模型

H = -JΣsᵢsⱼ - hΣsᵢ

哪怕每个人只轻微受邻居影响，只要局部对齐足够强，整体就可能从混杂态跃迁到强极化态。

  • 物理对应：磁性、自旋对齐、相变
  • 社会对应：政治极化、规范形成、群体对立
  • 关键直觉：社会撕裂有时是系统相变
空间流动

城市引力模型

Tᵢⱼ = k · PᵢPⱼ / dᵢⱼ^α

迁移、通勤、贸易和城市联系，往往并不是凭感觉，而像引力一样受到规模和距离共同支配。

  • 物理对应：万有引力
  • 社会对应：通勤、人流、贸易流、城际联系
  • 关键直觉：空间不是背景，而是力量
城市 / 创新 / 规模

城市尺度律

Y = Y₀N^β

很多城市指标不是线性随人口增长，而是按幂律放大。创新、专利、互动往往超线性增长，基础设施常次线性增长。

  • 物理对应：尺度、幂律、复杂系统
  • 社会对应：城市代谢、知识生产、创新密度
  • 关键直觉：城市真正生产的是相遇与连接
集体行动 / 跟风

阈值扩散

(Σaᵢⱼsⱼ / Σaᵢⱼ) ≥ θᵢ ⇒ sᵢ = 1

集体行动并不总靠“大家都很勇敢”，很多时候只是每个人心里有一条不同的点火线，临界一过就会连锁触发。

  • 物理对应：导通阈值、相变阈值
  • 社会对应：挑战赛、抢购、集体行动、规范扩散
  • 关键直觉：爆发前，系统可能看上去很安静

城市尺度律：城市真正生产的是什么？

调节人口规模 N 和指数 β。你会看到，当 β > 1 时，城市的某些产出会超线性增长——人口翻倍，创新和互动可能翻得不止一倍。这是“城市像超级生命体”的核心直觉之一。

阈值扩散：为什么很多爆发前都很安静？

每个人都有不同阈值：有人看到少数人行动就跟上，有人要看到半数以上才会动。调节“种子比例”和“平均阈值”，看看系统是零星响应，还是一路引发级联。

# 长期主义网站交互设计

## 核心交互功能

### 1. 时间线可视化工具
- **功能描述**: 交互式时间线，展示从短期到长期的时间跨度
- **交互方式**: 
  - 用户可以拖拽时间轴查看不同时期
  - 点击时间节点显示该时期的关键问题和解决方案
  - 支持缩放功能（从年到千年到百万年）
- **数据展示**: 气候变化、AI发展、生物灭绝等长期风险的演化过程

### 2. 风险评估矩阵
- **功能描述**: 交互式风险评估工具
- **交互方式**:
  - 用户可以选择不同的风险类型（环境、技术、社会、政治）
  - 调整时间尺度查看风险演变
  - 点击风险点查看详细分析和应对策略
- **可视化**: 使用ECharts创建动态散点图，X轴为发生概率，Y轴为影响程度

### 3. 决策影响模拟器
- **功能描述**: 展示当前决策对未来的影响
- **交互方式**:
  - 用户选择不同的政策或行动
  - 实时显示该决策在10年、100年、1000年后的影响
  - 支持多选项对比
- **数据模型**: 基于书中的理论和数据构建影响预测模型

### 4. 知识图谱浏览器
- **功能描述**: 探索长期主义相关概念的关联关系
- **交互方式**:
  - 点击概念节点查看详细信息
  - 拖拽节点重新布局
  - 筛选不同类型的概念（哲学、科学、政策等）
- **技术实现**: 使用力导向图展示概念间的复杂关系

## 页面结构设计

### 主页 (index.html)
- 英雄区域：展示长期主义的核心理念
- 核心概念卡片导航
- 交互式时间线预览

### 核心概念页面 (concepts.html)
- 知识图谱浏览器
- 概念详细解释
- 相关案例研究

### 时间线页面 (timeline.html)
- 交互式时间线可视化工具
- 历史事件和未来预测
- 关键转折点分析

### 风险评估页面 (risks.html)
- 风险评估矩阵
- 具体风险案例分析
- 应对策略建议

### 行动指南页面 (actions.html)
- 决策影响模拟器
- 个人和组织行动建议
- 资源链接和进一步阅读

## 用户体验流程

1. **发现阶段**: 用户从主页了解长期主义基本概念
2. **探索阶段**: 通过知识图谱深入了解相关概念
3. **分析阶段**: 使用风险评估工具理解挑战
4. **行动阶段**: 通过模拟器学习如何做出长期决策
5. **应用阶段**: 在行动指南页面找到具体的实施建议

## 技术实现要点

- 使用ECharts进行数据可视化
- Anime.js提供流畅的交互动画
- 响应式设计确保移动端体验
- 渐进式加载优化性能
- 无障碍设计确保可访问性

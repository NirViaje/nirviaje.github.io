分析能力卡牌｜元认知诊断｜树状路径训练

从“会不会算”转为“会不会分析”

本系统把一维伊辛模型题拆成连续的认知决策节点。每道选择题不是孤立考点，而是解题树上的一次判断：模型识别、相互作用能、平均场近似、自洽方程、临界温度、配分函数严格解。

读题建模经典电磁学求 J平均场替代自洽方程解个数与临界温度小 N 枚举转移矩阵推广

核心闭环

自旋变量 S=±1→能量模型 E→玻尔兹曼权重→配分函数 Z→宏观物理量

平均场分支的核心是：用邻居的局部影响替换为整体平均影响，再通过自洽方程判断相变。

题目三问对应能力

(1) 从磁偶极相互作用识别 J 的符号与量纲。

(2) 从最近邻相互作用过渡到平均场自洽方程。

(3) 从有限 N 枚举推广到任意偶数 N 的配分函数结构。

常见认知陷阱

把 J 的正负号当成纯代数问题；把平均场理解成“忽略相互作用”；把临界条件误认为“令磁化强度等于 1”；把配分函数当作普通求和而不识别结构。

学习方式

建议先用“开始闯关”走主路径，再用“随机训练”抽样测试。答错后不要只看答案，要看诊断提示对应的是哪张能力卡。

解题主线闭环

Root: 先确定模型层级 ├─ A. 模型读题：S=±1、最近邻、周期边界、玻尔兹曼权重 ├─ B. 经典电磁学：磁偶极场 → 相互作用能 → J 的符号 ├─ C. 平均场：邻居平均 → 全局平均 → h_eff ├─ D. 自洽方程：<S> = tanh[(h + J<S>)/kBT] ├─ E. 临界温度：h=0，斜率判据，推广到二维配位数 ├─ F. 严格解：N=2,3,4 枚举态与能量 └─ G. 任意偶数 N：转移矩阵特征值，Z_N = A^N + B^N

热弹性飞轮：从复杂建模题到决策树训练

本系统把一道包含摩擦、热传导、弹簧约束、稳态、线性稳定性和 von Mises 强度校核的综合题，改造成一棵可交互的选择题树。目标不是背公式，而是训练学生面对复杂题时的分析路径、错误诊断和元认知监控。

系统分解摩擦力矩热弹性耦合线性稳定性强度校核

1. 本题的核心闭环

这道题真正难的地方不在单个公式，而在变量之间形成闭环反馈：

ω↑→Pf=τfω↑→θ↑→N↑ / μ↓→τf 改变

其中，热膨胀使法向力上升，是正反馈；摩擦系数随温升下降，是负反馈。

2. 标准解题主路径

  1. 系统分解：飞轮、轴、摩擦面、弹簧、热边界。
  2. 摩擦建模：由压强积分求总压力和摩擦力矩。
  3. 热弹性约束：推出 N=N0+Kθ̄。
  4. 稳态热传导：求 θ0、θ̄ 与 τfω 的关系。
  5. 稳态转速：先解 β=0，再解 β>0。
  6. 稳定性：围绕稳态点线性化，分析特征根。
  7. 强度校核：求 von Mises 应力最大值。

3. 摩擦力矩入口

先用总压力反求压强系数，再算力矩。

N=∫bap(r)·2πrdr
τf=∫ba μp(r)·r·2πrdr

最常见错误：漏掉力臂 r，把力积分误当成力矩积分。

4. 热弹性关键式

轴的机械压缩和热膨胀通过弹簧约束耦合。

N=N0+Kθ̄

K 表示平均温升引起法向力变化的等效灵敏度。

5. 稳定性判断

围绕稳态点展开：

ω=ω*+δω，θ̄=θ̄*+δθ̄

稳定性看特征根实部；是否振荡看是否出现共轭复根。

6. 这套选择题树如何使用？

点击“开始闯关”，系统从 Root 节点开始。每个节点对应一次关键判断。选对后进入下一主路径；选错后会显示错误诊断，并指出这类错误属于读题、建模、耦合、稳定性还是强度判断问题。点击“节点地图”可以自由跳转；点击“随机训练”可以模拟蒙特卡罗式抽样，随机暴露薄弱节点。
